# Indian-Sign-Language
Normal humans can easily interact and communicate with one another, but the person with hearing and speaking disabilities face problems in communicating with other hearing people without a translator. In this project, we present a technique that uses the Bag of Visual Words model (BOVW) to recognize Indian sign language alphabets (A-Z) and digits (0–9). Segmentation is done based on skin colour as well as background subtraction. **ORB** and **HOG** features have been extracted from the images and with **SVM** and **CNN** are used for classification. The purpose of this project is to recognize all the alphabets and digits of Indian sign language using bag of visual words model.
